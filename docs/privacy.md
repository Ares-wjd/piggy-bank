# Piggy bank 개인정보처리방침

시행일: 2026년 10월 9일

Piggy bank(이하 "앱")는 가족이 쓰는 개인용 가계부 앱입니다. 앱은 다음과 같이 정보를 다룹니다.

## 1. 개발자가 수집하는 정보

**없습니다.** 개발자는 서버를 운영하지 않습니다. 사용자의 가계부 기록, 구글 계정 정보, 기기 정보를 받거나 보관하지 않습니다.

## 2. 앱이 기기 안에 저장하는 정보

- 가계부 기록: 자산 그룹·자산 이름, 금액, 날짜, 거래 내용
  - 기기 안 데이터베이스에 암호화해서 저장합니다(SQLCipher, Android Keystore).
- 로그인한 구글 계정의 이메일 주소: 설정 화면에 보여주고 백업할 계정을 정하는 데만 씁니다.
- 화면 설정: 디자인 선택, 합계 숨김 여부 등

안드로이드 자동 백업과 기기 간 데이터 이전은 꺼 두었습니다. 그래서 위 정보가 다른 곳으로 복사되지 않습니다.

## 3. 구글 드라이브 백업

- 사용자가 직접 로그인하고 허락하면, 앱이 **사용자 본인의 구글 드라이브**에 백업 파일을 저장합니다.
- 앱은 `drive.appdata` 권한만 사용합니다. 이 권한으로는 앱이 만든 **앱 전용 숨김 폴더**에만 접근할 수 있고, 사용자가 드라이브에 저장한 다른 파일은 보거나 바꿀 수 없습니다.
- 백업 파일은 사용자의 구글 계정 안에만 있으며, 개발자는 접근할 수 없습니다.
- 구글 드라이브에서 정보를 처리하는 방식은 [Google 개인정보처리방침](https://policies.google.com/privacy)을 따릅니다.

## 4. 앱 업데이트 확인

앱을 켜거나 업데이트를 확인할 때, 새 버전이 있는지 보려고 GitHub(github.com)에 접속합니다. 이때 가계부 기록이나 계정 정보는 보내지 않습니다. 다만 인터넷 접속 특성상 GitHub에는 기기의 IP 주소 등 일반적인 접속 정보가 남을 수 있습니다.

## 5. 제3자 제공

가계부 기록을 포함한 어떤 정보도 제3자에게 제공하거나 판매하지 않습니다. 광고와 분석 도구도 쓰지 않습니다.

## 6. 정보 삭제

- 기기 안 정보: 앱을 삭제하면 지워집니다.
- 구글 드라이브 백업:
  1. 구글 드라이브 웹사이트에서 **설정 → 앱 관리**로 갑니다.
  2. Piggy bank 항목에서 **숨겨진 앱 데이터 삭제**를 누릅니다.
- 앱의 드라이브 접근 권한 해제: [구글 계정 → 보안 → 내 계정에 액세스할 수 있는 서드 파티 앱](https://myaccount.google.com/connections)에서 Piggy bank의 액세스를 삭제합니다.

# Piggy bank

간단한 가계부 안드로이드 앱입니다.

- 수입·지출·이체를 기록하고, 은행·현금 같은 자산별 잔액을 자동으로 계산합니다.
- 기록은 휴대폰 안에 암호화해서 저장합니다.
- 백업은 **사용자 본인의 구글 드라이브**에 있는 앱 전용 숨김 폴더에 저장합니다.
- 개발자는 별도의 서버를 운영하지 않으며, 사용자의 가계부 기록을 볼 수 없습니다.
